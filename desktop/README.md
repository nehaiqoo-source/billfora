# BillFora desktop

Thin Electron shell around the same web app and login. No separate account.

## Run locally

1. From the repo root: `npm run dev`
2. In this folder:

```bash
npm install
npm run dev
```

That opens `http://localhost:3000` in a desktop window.

Point at a deployed URL:

```bash
BILLFORA_URL=https://your-deploy.example npm start
```
